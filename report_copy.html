Portfolio Analysis Report by Inaya PAGE

About This Project

This project is a Python tool that pulls historical stock data, calculates key risk/return metrics, and generates an HTML report.

What It Does

This project analyzes five stocks (Apple, Société Générale, Novartis, LVMH, and Boeing) across a 3-year period. It downloads historical price data, computes standard portfolio analytics, visualizes the results, and compiles everything into a clean report.

Key Features

  • Annualized Return: average yearly performance for each stock
  • Annualized Volatility: how much each stock's returns fluctuate (risk)
  • Sharpe Ratio: risk-adjusted return
  • Max Drawdown: worst peak-to-trough decline
  • Correlation Matrix: how much each stock pair moves together

What I Learned

Handling data gaps across different exchange calendars, applying real finance concepts in code, and building a full pipeline from raw data to a polished report.
